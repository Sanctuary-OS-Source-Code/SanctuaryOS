## macOS Universal Build Fix & Code Snippet Drawer Width Alignment

### Architecture & Visual Polish
- **macOS (`universal-apple-darwin` / `aarch64-apple-darwin`) Tauri Build Fix (`E0599` `WebviewWindowBuilder::transparent` & Cross-Platform Compiler Warnings) (`Cargo.toml`, `tauri.conf.json`, `deployment.rs`, `webauthn.rs`, `system.rs`):** Fixed the GitHub Actions macOS build failure (`error[E0599]: no method named 'transparent' found for struct 'WebviewWindowBuilder'` in `src-tauri/src/commands/deployment.rs`) and eliminated all 4 cross-platform Rust compiler warnings on non-Windows targets: (1) Added `"macos-private-api"` to `tauri` crate features in `src-tauri/Cargo.toml` and `"macOSPrivateApi": true` under `"app"` in `src-tauri/tauri.conf.json` so Tauri v2's `#[cfg(any(not(target_os = "macos"), feature = "macos-private-api"))]` gate exposes `.transparent(true)` for both the main Sanctuary OS window and the `lab-hud-overlay` window on `aarch64-apple-darwin` / `x86_64-apple-darwin`; (2) Scoped `serde_json::json`, `b64url_encode`, and `b64url_decode` in `src-tauri/src/commands/webauthn.rs` (and `crc32_ieee`, `write_png_chunk`, and `encode_bgra_to_png` in `src-tauri/src/commands/system.rs`) to `#[cfg(target_os = "windows")]`; (3) Removed duplicate inner `use tauri::Manager;` imports and refactored `os_version` initialization in `src-tauri/src/commands/system.rs` (`get_system_info`), and suppressed the unused `is_error` parameter on non-Windows targets in `notify_player_over_game` (`src-tauri/src/commands/deployment.rs`).
- **Comm-Link & Report Details `CodeSnippetSidebar` Width Alignment (`CodeSnippetSidebar.tsx`, `NexusReportsViewer.tsx`):** Matched `CodeSnippetSidebar.tsx`'s default width (`defaultWidth={760}`, `widthClass="w-[90vw] md:w-[760px]"`) to the `760px` Comm-Link (`MasonPostViewer.tsx`) and `Report Details` (`NexusReportsViewer.tsx`) `<SidePanel>` drawers it opens from, eliminating the `1000px` overhang while still supporting drag-resizing, `1220px` Split/Reference view, and Fullscreen expansion.
- **Screenshot Tour — Full 43-Subsection Elevated Hub Matrix & Automated SidePanel Drawer Capture (`ScreenshotTourSidePanel.tsx`, `App.tsx`, `TitleBar.tsx`, `GlobalCommandPalette.tsx`, `TimeCapsule.tsx`, `ReleaseNotesShowcase.tsx`):** Expanded `ScreenshotTourSidePanel.tsx` with granular selection for all 43 subsections across the 5 Elevated Hubs (`{Mason} Workshop` (7), `Architect Console` (9), `Oversight Command` (10), `Wayfinder Operations` (9), and `Keepers Core` (8)) grouped by hub with per-hub `All`/`Clear` batch toggles, plus a dedicated 22-drawer **Panels & Drawers** capture matrix (`Active Workspaces`, `System Queues & Updates`, `Notifications`, `Command Palette`, `{Mod} Dossier`, `Quick Swap {Blueprints}`, `{Blueprint} Architect`, `Sanctuary Alerts`, `Conflicts Detected`, `Incompatible {Mods}`, `{Mod} Updates Detected`, `Conflict Radar Sweep`, `{Vault} Dropzone`, `{Blueprint} Signature Queue`, `Scout Queue`, `{Nexus} Updates`, `{Backups} Snapshot Inspector`, `Release Notes & Changelog`, `Support Hub`, `My Support Tickets`, `System Status`, and `System Log History`) that automatically opens each selected `<SidePanel>`, captures the native PNG screenshot, and closes the drawer cleanly, alongside a new **Delayed Snap (3s)** trigger for capturing any custom nested sub-panel or menu.
