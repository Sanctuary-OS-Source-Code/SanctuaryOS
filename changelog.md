## Homestead Sandbox Hardening, Database-Driven Diagnostics & Schema Visual Studio Refinement

### Architecture
- **Database-Driven Known Exception Rules (`public.known_exception_rules`):** Decoupled community Known Error & Exception Rules completely from `sanctuary_schemas` into a dedicated Spoke database table (`public.known_exception_rules` in `schema.sql` and live Spoke infrastructure) with full RLS governance and `game-gateway` (`STAFF_ONLY_TABLES`) routing. `KnownExceptionRules.tsx`, `ArchitectHomesteadDiagnostics.tsx`, `ArchitectCommandScreen.tsx`, and `Lab.tsx` now hydrate, cache, and upsert Known Error rules directly against the Spoke database while keeping live runtime rules synced to the Tauri verification engine.
- **100% Database-Driven DLC Catalog Resolution:** Retired the legacy schema-level `dlc_catalog` dictionary across `SchemaVisualStudio.tsx`, `modUtils.tsx`, `ArtifactRulesTab.tsx`, `WayfinderMasterSchemas.tsx`, `gameArchitecturePresets.ts`, and all Master Schema payloads so DLC metadata resolves exclusively from the Spoke `public.dlc_registry` database table while retaining lightweight engine folder/prefix scan descriptors (`dlc_subdirs`, `dlc_folder_prefixes`, `dlc_file_extensions`).
- **Ephemeral Sandbox Save Rewind & Chronological Lab Reports:** Updated Homestead's sandbox verification flow (`deployment.rs`, `Lab.tsx`) so in-engine save checkpoints validate real disk writes during Stage 4 and automatically rewind the mounted test save slot back to its pristine airgapped baseline upon session teardown—preventing corrupted mods from ever tainting the reusable test save—while sorting `Lab Reports` strictly from most recent to oldest.

### Visual Overhauls
- **Schema Visual Studio Decluttering (`SchemaVisualStudio.tsx`):** Removed the redundant `DLC & Expansion Pack Catalog` and `Known Exception & Diagnostic Rules` groups from the Master Schema Editor and updated the top `<SidePanelFilterBar>` `<DashboardStatTile>` counters to surface binary, external tool, and log-matcher counts cleanly.
- **Zero Native Browser Hovertips OS-Wide (`<HoverTooltip />`):** Eliminated all native Chromium HTML5 constraint-validation hovertips (such as `stepMismatch` popups on `GlassNumberInput` and `NumberListBuilder` numeric controls, plus `type="email"` / `type="url"` / `required` form inputs across `SchemaVisualStudio.tsx`, `ArchitectHomesteadDiagnostics.tsx`, `ArtifactScout.tsx`, `AuthWrapper.tsx`, `WayfinderSidePanels.tsx`, `WorkbenchTemplateBuilder.tsx`, `FlagContentSidePanel.tsx`, and `NexusSidePanels.tsx`) and replaced all remaining native `title` attributes in `ArchitectSupportTickets.tsx` and `KeepersSupportTickets.tsx` with glassmorphic `<HoverTooltip />` overlays.
