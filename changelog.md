## The Glassmorphism & Core Stability Overhaul


### Architecture/Bug Fixes
- **Cached Changes Banner Visibility:** Fixed an issue where the "cached changes from your last session" notification pill on startup was being instantly overwritten by the radar sweep status. Increased the display delay (from 2000ms to 8000ms) to ensure the banner appears after the initial boot scan completes, giving users a clear chance to see it.
- **IDE Problems Panel Icon Rendering:** Fixed a bug in `MasonEditorPanel` and `WorkbenchRawEditor` where the 'cancel' icon was improperly rendering as raw text (e.g., "Abort" or "Cancel") when thematic lexicons were active. Corrected the Material Symbols ligature by replacing the translated UI string `t("nav_cancel")` with the strict icon identifier `t("icon_cancel")`, ensuring the `X` icon always renders correctly regardless of the active language theme.
- **Mason IDE & File Hook Proxy Bypassing:** Fixed a critical bug where `MasonIDE.tsx` and `useMasonFiles.ts` were manually invoking `getActiveGameClient()` instead of using the central `supabase` magic proxy. This caused cloud saves and file deletions in the IDE (e.g. `secure_upsert_cloud_file`) to bypass the Edge Function API Gateway and attempt direct RPC calls against the Legacy Fallback database, resulting in a persistent 404 error. The imports have been updated to properly utilize the `.supabase` proxy export.
- **Hover Physics & Z-Index Stability:** Consolidated `zIndex` architecture to respect Chromium rendering bounds (< `2147483647`). Modals and dropdowns now reliably use `#sa-portals`. Standardized Physical Levitation `hover:-translate-y-1` on interactive surfaces (Stat Tiles, Quick Links, Universal Comm Cards) rather than scaling. Fixed duplicate CSS shadow overrides that prevented UniversalCard hover effects from triggering on Comm Cards.
- **Wayfinder Post Management (Silent Failure):** Fixed a critical bug in `WayfinderPostsEditor` where creating or deleting Dispatch/Alert posts would silently fail (showing "Transmission Updated!" but not actually saving the data). The editor now correctly routes updates and deletions through the OS Edge Function proxies (`secure_upsert_cloud_file`, `secure_delete_cloud_file`) to bypass game database RLS limitations, and explicitly catches empty returns to prevent silent false-positives.
- **Mason IDE UI Overlaps & Strict Validation:** Fixed multiple UI layout issues where the missing keys validation bar and the syntax error popups were heavily overlapping each other and the bottom of the Monaco editor. The validation stats bar has been cleanly relocated directly into the side panel footer, adjacent to the Publish button. Furthermore, a strict JSON validation guard was added: users can no longer circumvent missing schema key restrictions by intentionally submitting invalid JSON (like `"--"`) to crash the parser, as the publish action is now forcibly disabled upon parsing errors or missing validation stats.
- **Stacked Side Panel Visibility:** Removed the legacy CSS rule (`:has(~ .sa-side-panel-wrapper)`) from `index.css` that would automatically force underlying side panels to 0% opacity when multiple panels were opened simultaneously. Since all side panels now feature fully structured backgrounds and glassmorphism, they natively stack on top of each other gracefully without requiring artificial visual culling.
- **Edge Function Proxy (23505 Duplicate Key):** Updated the `game-gateway` Edge Function to explicitly intercept and safely ignore `23505` (Duplicate Key Constraint) violations during generic `upsert_cloud_file` operations (such as recording a post view). This prevents non-critical unique constraint errors from bubbling up to the client and polluting the console when users view posts they have already seen.
- **Game Database Authentication (401 Unauthorized):** Added strict `session.access_token` validation to the OS Edge Function proxies to completely eliminate the flood of 401 Unauthorized errors caused by unauthenticated users or expired sessions triggering the view logger. Fixed an issue where actions on Mason profiles and feeds (Following, Liking, and Viewing posts) were failing with a 401 error. Replaced direct client-side insertions with the dedicated OS Edge Function proxies (`secure_upsert_cloud_file`, `secure_delete_cloud_file`, `secure_toggle_mason_follow`) to securely route operations cross-project using the appropriate Service Role keys.
- **Hero URLs (Post Editors):** Fixed a critical parsing bug where Hero URLs would get wiped out when editing existing posts if the URL was initially inserted as standard Markdown or HTML. Updated the regex in `extractPostImage` to properly extract newlines and unified the `rawContent` stripper across `MasonPostsEditor`, `WayfinderPostsEditor`, and `KeeperPostsEditor` to enforce precise regex replacement that catches and cleans up all format variations correctly.
- **Mason Profile Hub Layout:** Repaired a severe layout overlap issue in the Mason Profile Overview.
