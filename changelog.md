## Main Update Title

### Architecture
- **Web Landing Page Architecture:** Completely reimagined the Web Landing Page layout structure. Discarded the rigid dashboard models and generic web containers in favor of a sleek, asymmetrical **Bento-Box Feature Grid**. This layout closely mirrors the successful Mason Profile Showcase, packing the Workspaces, News, and Download sections into tightly integrated glass panels that flow dynamically across the viewport. Crucially, all inner elements (News Cards, Workspace Tiles) were flattened by removing redundant `glass-panel` wrappers to eliminate the clunky "box-in-a-box" rendering, resulting in a cohesive, edge-to-edge pane of glass aesthetic.

### Architecture & Security
- **Hardware ID Privacy Masking:** Refactored the authentication and anti-malware systems to cryptographically hash your device's Hardware ID before it is ever sent to Supabase. This creates a one-way fingerprint that maintains the ability to detect bans while guaranteeing the raw Hardware ID is permanently masked from the global databases, effectively ensuring zero-knowledge privacy for device telemetry.
- **Web Environment Gateway:** Implemented a global environment detection utility to safely restrict heavy desktop-exclusive features (Vault, Radar, Workbench, etc.) from loading when running Sanctuary OS as a standard website. This cleanly decouples the frontend to act as both a web app and a Tauri desktop application without modifying the core logic of the 70+ desktop components.
- **Two-Factor Authentication (2FA):** Integrated a comprehensive TOTP Multi-Factor Authentication system. Added a new Security tab in settings for QR-code enrollment, and refactored the primary login flow to intercept the session state and require a 6-digit challenge code before upgrading the user to AAL2 security.
- **Settings Architecture:** Merged the standalone Security Tab into the Core Tab under the Network Credentials section for a more streamlined UI. The 2FA setup now operates dynamically within a modern, animated glassmorphism side panel instead of a dedicated tab, while seamlessly persisting the new localized lexicon string constraints.
- **2FA Fallback Enhancements:** Implemented dual fallback protections for 2FA within the enrollment flow due to Supabase Auth limitations regarding static backup codes. Added an explicit UI mechanism that extracts and presents the raw TOTP setup key for users to copy and securely stash, alongside persistent UI prompts encouraging the enrollment of secondary backup devices.
- **Web Multi-Domain Architecture:** Implemented a new routing infrastructure for the web version. Users visiting the root domain will now see a premium WebLandingPage with a 'Nexus' Workspace selector. Selecting a workspace redirects to a dynamic subdomain (e.g., sims4.domain.com), which automatically triggers the Sanctuary OS to initialize the corresponding game schema.
- **Web UI Accessibility:** Re-enabled access to the 'Settings' and 'Alerts' panels for web users via the SystemStatusBar and Sidebar. Desktop-exclusive settings are safely gated behind environment checks to prevent crashes.
- **Web Landing Page Overhaul:** Completely revamped the root `WebLandingPage.tsx` interface to include dynamically fetched 'Sanctuary Foundry News' announcements directly from the Supabase broadcast system, eliminating the need for hardcoded patches. Added premium desktop download link sections and expanded the legal footer with localized links.
- **Web Workspace Command Center:** Refactored web routing so that navigating to a workspace subdomain (e.g., `sims4.sanctuary-os.com`) now dynamically loads a web-safe version of the `CommandCenter.tsx` interface rather than the initial setup grid. This brings the full System Broadcast Alerts and Feed ecosystem directly to web users, with desktop-only tools (Vault, Radar) safely hidden away.
