### Architecture/Bug Fixes
- **Wayfinder Post Management (Silent Failure):** Fixed a critical bug in `WayfinderPostsEditor` where creating or deleting Dispatch/Alert posts would silently fail (showing "Transmission Updated!" but not actually saving the data). The editor now correctly routes updates and deletions through the OS Edge Function proxies (`secure_upsert_cloud_file`, `secure_delete_cloud_file`) to bypass game database RLS limitations, and explicitly catches empty returns to prevent silent false-positives.
- **Edge Function Proxy (23505 Duplicate Key):** Updated the `game-gateway` Edge Function to explicitly intercept and safely ignore `23505` (Duplicate Key Constraint) violations during generic `upsert_cloud_file` operations (such as recording a post view). This prevents non-critical unique constraint errors from bubbling up to the client and polluting the console when users view posts they have already seen.
- **Game Database Authentication (401 Unauthorized):** Added strict `session.access_token` validation to the OS Edge Function proxies to completely eliminate the flood of 401 Unauthorized errors caused by unauthenticated users or expired sessions triggering the view logger.
- **Hero URLs (Post Editors):** Fixed a critical parsing bug where Hero URLs would get wiped out when editing existing posts if the URL was initially inserted as standard Markdown or HTML. Updated the regex in `extractPostImage` to properly extract newlines and unified the `rawContent` stripper across `MasonPostsEditor`, `WayfinderPostsEditor`, and `KeeperPostsEditor` to enforce precise regex replacement that catches and cleans up all format variations correctly.
- **Game Database Authentication (401 Unauthorized):** Fixed an issue where actions on Mason profiles and feeds (Following, Liking, and Viewing posts) were failing with a 401 error. Replaced direct client-side insertions with the dedicated OS Edge Function proxies (`secure_upsert_cloud_file`, `secure_delete_cloud_file`, `secure_toggle_mason_follow`) to securely route operations cross-project using the appropriate Service Role keys.
- **Mason Profile Hub Layout:** Repaired a severe layout overlap issue in the Mason Profile Overview. Replaced the error-prone Flexbox (`flex-col xl:flex-row`) wrapper with a robust CSS Grid implementation (`grid-cols-1 xl:grid-cols-[1fr_480px]`) for the COMM-LINK and SHOWCASE panes, completely eliminating any possibility of horizontal collapsing and rendering overlap.

Migrated the header wrapper to a structured CSS Grid (`grid-cols-1 xl:grid-cols-[auto_1fr_280px]`), ensuring the buttons are strictly constrained to 280px while the bio text correctly fills the remaining space without wrapping prematurely.
- **System Log Modal:** Fixed an issue where the System History panel was jumping to the top of the header. It is now properly portalled to the document body so it floats correctly in the corner.
