## Welcome to Sanctuary OS v0.6.0-Dev.14!

This Dev Build hardens Desktop and Cloud workflows from end to end: introducing a read-only, consent-gated **Cloud-Sync Folder Sentinel** across every major desktop sync client, locking down multi-workspace setups so workspaces never overwrite each other, upgrading Partner Spoke security to a **Split-Custody Double-Envelope Vault** with scoped gateway tokens, rewinding Homestead's **Groundhog Sandbox** save slots automatically after every test run, refining Sanctuary OS's **Neutral Specular Liquid Glass** design with **3D WebGL2 Dropdown Refraction**, **Lead Action Cards**, and a decluttered **Workbench IDE**, and overhauling **Collections**, **Game Version Filtering**, **Family Mass Updates**, and **Keepers Ecosystem Threat Oversight**. Here is everything new in plain English.

### TL;DR — The 60-Second Summary

- **Cloud-Sync Folder Sentinel & Pre-Launch Symlink Guard:** Before Sanctuary projects symlinks or launches your game, a read-only check scans OneDrive, Google Drive for Desktop (including `"My Computer"` folders), iCloud Drive, Dropbox, Box, Nextcloud, ownCloud, Proton Drive, MEGA, pCloud, Syncthing, and Resilio Sync—halting risky sync overlaps until you choose local pinning, Vault relocation, subfolder sync exclusions, or **Session-Only Mods**.
- **2-Step Workspace Setup, Multi-Workspace Persistence & Onboarding Step 1:** Launching a fresh Desktop workspace opens a guided side-panel setup for folder auto-detection and per-workspace aesthetics without risking cross-workspace overwrites, while new-user onboarding now lets you live-switch between **Standard English** and **Sanctuary** terminology plus pick your Chameleon theme before account setup.
- **Neutral Specular Liquid Glass, 3D WebGL2 Dropdowns & Lead Action Cards:** Replaced neon borders OS-wide with neutral Liquid Glass rims, routed real-time WebGL2 refraction into all dropdowns and context menus, introduced Slot #1 **Lead Action Cards** across Blueprints, Collections, Workbench, and Creator Hubs, and organized **System Queues** into a clear 4-tier severity order.
- **Database-Driven Diagnostics, Ephemeral Save Rewind & Privacy-First Compliance:** Moved DLC catalogs and Known Exception Rules to Spoke tables for instant updates, guaranteed zero save-tainting in Homestead Lab via automatic post-test save rewind, added live Companion **Patch Fire Drill** simulations on Web/PWA, and upgraded Compliance checks so Tier 1–4 counters never expose restricted names or URLs.
- **Highlander Swap Prompts, Clean Collections & Redesigned Workbench IDE:** Decoupled **Exclusive Slot** tags into inline Metadata controls and Vault filters, rebuilt **Collections** around strict Tier-0 health checks and compact asset grids, replaced legacy statuses in Oversight with Sanctuary's 5 canonical mod states (**Stable**, **Unstable**, **Corrupted**, **Under Review**, **Pending**), and decluttered the **Citizens Workbench** category grid and search bar.
- **Split-Custody Spoke Vault & Scoped Gateway Tokens:** Retired plaintext Spoke service-key storage in favor of salted scoped gateway tokens and double-envelope Vault encryption with 1-click token rotation, instant **Cut the Cord** revocation, and cross-Spoke Ecosystem Threat Manifest pulling for Keepers Core.

### Cloud-Sync Folder Sentinel, Multi-Workspace Persistence & Guided Setup

- **Proactive Cloud-Sync Overlap Detection (12+ Providers):** Sanctuary inspects configured Master Vaults, workspace Vaults, Mods targets, User Data folders, and Game Roots in read-only mode—detecting OneDrive Known Folder Backup and NTFS Files On-Demand placeholders, Google Drive for Desktop `"My Computer"` folder syncs, Dropbox, iCloud Drive, Box, Nextcloud, ownCloud, Proton Drive, MEGA, pCloud, Syncthing, and Resilio Sync without automatically touching your files.
- **Consent-Gated Fixes & Session-Only Symlink Mode:** If an overlap is found before equipping a Blueprint, swapping in Homestead Lab, or pressing Quick Launch, Sanctuary pauses cleanly and puts you in control: keep files pinned locally, relocate your Master Vault safely, copy Save Folder isolation paths, add native sync exclusions, open your sync client directly, or opt into **Session-Only Symlinks** that automatically unlink symlinks as soon as your game closes and clear the **Command Center** alert tile automatically.
- **Rock-Solid Multi-Workspace Memory & Guided Setup Side Panel:** Switching between multiple games or test workspaces no longer risks wiping paths or surfacing half-configured spaces as active. Fresh workspaces open a 2-step **Guided Setup Drawer** overlaying Command Center with schema-based game and mod-folder auto-detection, conditional Master Vault confirmation, per-workspace theme and language previews, and clean cancel rollback.
- **Step 1 Personalization Onboarding & Signature Codenames:** New users start onboarding by testing **Standard English** vs. **Sanctuary** glossaries live and picking a Chameleon theme before orientation and Legal Covenants. Across System Directives and the unified 4-tab **Interactive Forking Guide**, Sanctuary features also now use clear signature codenames—such as **Groundhog Sandbox**, **Patch Fire Drill**, **Save Doctor**, **Zero-Copy Exodus**, and **Bytecode Hound**—with inline SQL and token guides built right into Spoke panels.

### Companion Patch Fire Drill, Highlander Slot Tags & Collections Overhaul

- **Zero-PII Companion Patch Fire Drill on Web & PWA:** Encrypted Desktop Companion Vault snapshots now carry schema-agnostic compatibility versions and script flags, unlocking live **Patch Fire Drill** patch-readiness simulations and 6 real-time rig telemetry tiles right from your browser without exposing local folder paths or private hashes.
- **Highlander Exclusive Slots Unlocked Everywhere:** Creators and Architects can pick or create **Exclusive Slot** tags directly inside Metadata Studio (or Sidecar manifests), view rival items occupying the same slot, filter by Exclusive Slot inside **Your Vault** and **Architect Console**, and trust mod swaps to protect independent add-on modules while only inheriting slots onto script/module twins.
- **Tier-0 Collection Integrity & Focused Management Drawers:** Collections now enforce automatic Tier-0 and unflagged safety filtering so restricted or broken files never linger in published sets. The rebuilt **Manage Collection** drawer separates inline member filtering from a centered, searchable `+ Add` catalog picker in Slot #1, replaces redundant status tags with clean telemetry tabs (**Collections**, **Issues**, **Empty**), and opens Mod Dossiers on click.
- **Unified Tier-0 Catalog Counts Across Hubs & Nexus:** Strict deduplicated Tier-0 counters keep **Command Center**, **The Nexus**, and all Creator/Architect hubs synchronized immediately after every moderation or catalog change, hiding already-installed items cleanly by default (`Hide Installed`) and formatting `Nexus` grammar naturally across themes.

### Specular Liquid Glass, 3D WebGL2 Dropdowns, Lead Action Cards & Workbench Polish

- **Neutral Specular Liquid Glass & 3D WebGL2 Menus:** Replaced harsh colored/cyberpunk borders across cards, badges, checkboxes, buttons, and inputs with neutral specular Liquid Glass rims—reserving semantic colors purely for icons, text, and metric values—while extending real-time WebGL2 background refraction onto portaled dropdown menus and context menus, plus custom Liquid Glass hovertips replacing all native browser tooltips OS-wide.

- **Refined Workbench IDE (`Visual Schema` Bar & Clear Category Contrast):** Moved template switching into a dedicated **Visual Schema** header card above search so dropdowns never crowd the search input, tucked Modified/Unsaved/Category filters into a clean `Filters` popover with flush reset actions, added high-contrast active category states (lit icon tiles and bordered count capsules) plus a `Categories (N)` `Show All / Show Less` header toggle, and upgraded Template Builder's Categories drawer into a 3-column grid with crisp Material icons.

### Immortal Sandbox Save Rewind, Database Diagnostics & Privacy-First Compliance

- **Zero-Taint Groundhog Sandbox Save Rewind:** Homestead Lab validates real in-game saves during Stage 4 and automatically rewinds the mounted test save slot back to its untouched airgapped baseline on teardown, ensuring experimental or unstable mods never corrupt your reusable test save while listing **Lab Reports** newest-first.
- **Live Spoke DLC & Known Exception Rules:** DLC catalogs (`public.dlc_registry`) and community Known Error Rules (`public.known_exception_rules`) now resolve and sync directly from database tables rather than static Master Schema JSON bundles, letting updates roll out without client patches.
- **Privacy-Preserving Tier 1–4 Compliance & Deduplicated System Logs:** Upgraded hashed compliance hydration to return only `(hash, tier)` metadata pairs—keeping restricted asset names, creators, and links completely private while illuminating **Blueprint Sync**, **Support Lock**, and compliance audits cleanly. **System Logs** also now collapse noisy repeated cache messages, organize **Homestead Lab** logs into a dedicated tab, and parse crash traces inside a readable inspector.

### Split-Custody Spoke Gateway Tokens, Family Mass Update & Ecosystem Threat Oversight

- **Split-Custody Spoke Vault & Scoped Gateway Tokens (`spk_gw_*`):** Communities hosting Partner Spokes keep full ownership behind salted, scoped gateway tokens paired with double-envelope Vault encryption (`HKDF-SHA256` + `AES-256-GCM` KMS-wrapped storage), secret-free uplink bundles, 60-second zero-downtime key rotation, instant **Cut the Cord** revocation, FIDO2 Verified Creator publishing locks, and zero-key audit redaction.
- **Family-Grouped Oversight Mass Update & Hover Mini-Dossiers:** Scoped **Mass Update** exclusively to **Oversight Command** using Sanctuary OS's 5 canonical mod statuses (**Stable**, **Unstable**, **Corrupted**, **Under Review**, **Pending**). Grouped mod families display rich card hover mini-dossiers and a clear footer-right `+{N} Modules` button opening a smooth inline family drawer with 1-click **Select Family** cascading, paired with searchable **Mason** filters, Shift+Click range selection, chunked batch execution, and a streamlined edit drawer.
- **Keepers Ecosystem Malware Manifests, Compliance Cleanup & Tiered Audit Logs:** **Keepers Core** now auto-pulls live Partner Spoke threat reports with top-right Spoke badges, non-overlapping card consoles, 2-column **Grouped Threat Reports** drawers, standardized **Threat Manifest Dossiers** with SHA-256 copy buttons, and 1-click **Promote to Core Heuristic** drafting. Compliance Oversight focuses strictly on Tier 1–4 `Pending`/`Confirmed` reviews and Tier 0 clearance with separate hash/lineage panels, while **Audit Logs** format human-readable labels and scope sensitive token or ticket events by clearance level.
