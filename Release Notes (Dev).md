## Welcome to Sanctuary OS v0.6.0-Dev.15!

**v0.6.0-Dev.15** completes Sanctuary OS's transition into a 100% game-agnostic, multi-engine modding operating system. Across this release, we shipped the full Phase 14 modding parity pillar (**The Quartermaster** FOMOD/BAIN wizard, **The Rosetta Protocol** modlist translator, **Zero-Copy Exodus** MO2/Vortex importer, **Save Doctor** pre-launch warnings, and **Creator Airlock** save-airgapped tool sessions), rebuilt game version detection and load ordering on a deterministic **Master/Dependency DAG** and multi-engine **Binary Container TOC** scanner, hardened **ByteHound v3** with `> 8 MiB` streaming inspection and `.7z`/`.rar` auditing, sealed local creator API tokens inside DPAPI/`AES-256-GCM`, moved mod categories into relational `public.taxonomy` tables, simplified **The Cartographer** onboarding, modularized the codebase, eliminated macOS Universal build OOM crashes, and unified every legal covenant and system directive with reality. Here is everything new in plain English.
